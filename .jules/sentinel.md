## 2026-06-18 - Prevent XSS in Inline Event Handlers
**Vulnerability:** Found 168 instances of critical DOM-based Cross-Site Scripting (XSS) in `index.html` where variables (e.g., `task.id`, `log.id`) were interpolated directly into inline `onclick` attributes.
**Learning:** Even when wrapped in `escapeHTML()`, string interpolation within inline event handlers (like `onclick="..."`) is unsafe because the browser performs HTML entity decoding before parsing and executing the JavaScript, leaving the application vulnerable to payload injection.
**Prevention:** Remove all inline event handlers. Bind data to the DOM using `data-*` attributes (e.g., `data-action`, `data-id`) and handle interactions securely via a global event delegation listener (e.g., `document.addEventListener('click', ...)`).
